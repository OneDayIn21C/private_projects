## 공통 프레임워크

모든 종목 문서는 같은 구조를 따른다:

1. **현황** — 최신 실적·밸류에이션 스냅샷
2. **투자 논지** — 강세/약세 논거 (10년을 들고 갈 이유와 깨질 조건)
3. **10년 시나리오 밸류에이션** — 약세/기본/강세 3개 시나리오의 연환산 수익률
4. **적립 전략** — 월 정액 규칙 + 변동성 활용 규칙(하락 시 증액, 급등 시 정액) + 점검 체크리스트 + 적립 중단(Exit) 조건
5. **한 줄 결론**

## 공통 원칙

- **정액 적립이 기본, 판단은 예외.** 매수 시점 판단은 하지 않는다. 판단이 개입하는 건 정기 점검과 사전에 정한 가격/지표 트리거뿐.
- **본전은 목표가 아니라 부산물.** 평가할 것은 "지금 가격에 앞으로 10년 살 만한가"이지 과거 평단이 아니다.
- **규칙이 깨지면 기계적으로 멈춘다.** 각 문서의 Exit 조건 발생 시 신규 적립 중단 → 관찰 → 논지 회복 불가 시 분할 매도.
- **공포 구간 대량 청산 금지** (2026-08-20 신설, 원칙 5). 공포탐욕 <25 에서는 사전에 정한
  손절선에 의한 매도가 아닌 한 보유분의 25%를 초과해 팔지 않는다. 근거: PLTR 2022-10-03
  100주 일괄 청산 = 계좌 최대 단일 기회손실 −$16,275.
- **"매수 안 함"도 명시적 판정이어야 한다** (2026-08-20 신설, 원칙 6). 적립 대상에서 제외할
  때는 제외 사유(비중/밸류/논지)와 **재편입 조건을 숫자로** 함께 적는다. 근거: PLTR 이
  사유만 있고 재편입 조건이 없어 21개월(2024-11~2026-08) 공백이 발생했다.
- **종목 추가 시**: `티커_한글명/` 폴더를 만들고 같은 프레임워크로 문서를 작성한 뒤 위 인덱스에 행을 추가한다.
